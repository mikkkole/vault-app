# Vault - Деплой на Railway.com

> Дата: 2026-07-24
> Продукт: Vault - приложение для учёта и поиска личных вещей
> Стек: Node.js (Express) + PostgreSQL + Vanilla JS frontend
> Цель: рабочее приложение на Railway.com

## Цель

Рабочее приложение на Railway.com:
- Пользователь может зарегистрироваться, войти
- Добавить вещь с фото
- Найти вещь по поиску
- Просматривать хранилища (шкафы/полки)

## Архитектура (MVP)

Один сервис: Express раздаёт API + статику из `public/`.

```
┌─────────────────────────────────┐
│        Railway Project          │
│                                 │
│  ┌─────────────────────────┐    │
│  │      Web Service        │    │
│  │     (Node.js + Express) │    │
│  │                         │    │
│  │  /api/*  → Express API  │    │
│  │  /*      → public/      │    │
│  │                         │    │
│  └────────────┬────────────┘    │
│               │                 │
│      ┌────────▼─────────┐       │
│      │    PostgreSQL    │       │
│      │   (Railway DB)   │       │
│      └──────────────────┘       │
│                                 │
│  Photos → Cloudinary (бесплатно)│
└─────────────────────────────────┘
```

- Railway Free tier: $5/мес (500 часов)
- PostgreSQL Free: 1GB storage
- Cloudinary Free: 25GB storage

**Итого:** ~$5/мес или бесплатно на Free tier (с ограничениями).
